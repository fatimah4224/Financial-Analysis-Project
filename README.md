# Financial Analysis Project

## Description
This project focuses on analyzing financial data to compare budgets versus actual expenses.
The analysis includes data cleaning, feature engineering, and visual insights using Power BI.

## Objectives
- Clean and prepare financial data using Python.
- Create key financial indicators (budget variance, expense ratios).
- Visualize insights through an interactive Power BI dashboard.

## Tools Used
- Python (Pandas, NumPy)
- Power BI

## Files
- cleaned_financial_data.csv: processed dataset
- untitled2.py: data cleaning and feature engineering script

## Output
The project highlights spending patterns and budget deviations to support financial decision-making.

## Notes
The dataset is simulated and intended for analytical practice.
